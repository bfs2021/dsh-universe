# DSH Universe

[English](README.md) | 中文

把你在 DeepSeek Harness 里的一天画成一座像素小城：每个会话是一栋楼，每个代理是一个人。看一眼就知道什么在跑、
什么在等你、今天做完了什么。

![示例数据中的城市](screenshots/city.png)

## 能看到什么

- **城市**：每个会话一栋楼，随着会话的工作长高。需要你的代理（等批准、等回答、等你看计划）在广场上举牌。
- **今天**：顶部一排按钮：需要你的、下一个定时任务、正在运行的、待查看的结果、失败的调用和 token 用量。点一下就跳过去。
- **只看**：定时任务、运行中、待查看、出错、token 用量、调用量，每次只看一类，其余变灰。
- **楼里**：每类工作一层，代理站在自己干活的地方。
- **时间轴**：拖回今天任意时刻，或者回放一整天。
- **清单**：城市里的一切都有文字版，方便读屏和小屏幕。

指针移到楼上，点卡片上的 **打开会话**，就回到 DSH 里的那个会话；点楼本身就进楼里。

## 安装

需要 DeepSeek Harness 0.2.2-rc.2 或更新版本。

1. 打开 **插件**，点 **添加插件**。
2. 输入 `@khglobal/dsh-universe`，点 **安装**。
3. 显示 **已安装** 后，点 **立即启用**。

侧栏里随即出现 **DSH Universe**，不用重启。

**命令行**（高级用户）：

    dsh plugin --profile web add @khglobal/dsh-universe

把 `web` 换成你的配置名。用命令行安装后要重启 DSH。

## 读什么

只读元数据，而且只在你自己的设备上：

- 时间、工具名、每次调用的类别、token 数、调用是否失败；
- 会话和工作区标题（DSH 自己的列表里本来就显示的那些）、模型名、连接器名和状态、已装的插件和技能、定时任务的名称和时间。

**从不**读你的消息、模型的回答和思考、工具参数和结果、文件内容、报错正文和文件路径。子代理按预设名显示，不显示它的提示词。

## 隐私

- 不上传任何东西。插件自己不发网络请求，面板只和你本机的 DSH 通信。
- 不往任何提示词里放内容，也不给模型加工具。
- 当天的汇总存在本机 DSH 的存储里，保留 14 天。每台设备各有一座城，不同步。
