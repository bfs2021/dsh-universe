# DSH Universe（`@khglobal/dsh-universe`）

把工作区画成一座小城：会话是楼，代理是城里的人。侧栏有一个入口，打开后是城市面板、清单和今天栏。

只读宿主的元数据（会话状态、工具名、用量、时间），不读会话正文、计划正文和回答。

## 桌面与云端

- 两端都能用，插件包相同。
- 城市的落位存在各自宿主的存储里：桌面和云端各是一座城，不同步。
- 云端插件装好后要等工作区下次启动才加载。

## 安装

在 DSH 里：打开 **插件**，点 **添加插件**，输入 `@khglobal/dsh-universe`，点 **安装**。
